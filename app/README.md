# Android App

Gradle 工程根目录就是 `app/`。

| 模块 | 内容 |
|---|---|
| `core/protocol` | 纯 Kotlin/JVM：`PocketClient`（WebSocket）、`Transport`（Tailscale / LAN 路由标签）、`TranscriptReducer`、模型等数据结构 |
| `app` | Compose 界面、连接管理、前台服务（审批通知）、Keystore 加密 token |

界面和操作以官方 dsh 桌面/Web 为基准，配色和圆角沿用其主题；[docs/mockups](../docs/mockups/) 仅作早期设计参考，当前实现见 [功能对齐说明](../docs/desktop-parity.md)。

## 构建

真实模型端到端（仅本地，需要 `DEEPSEEK_API_KEY`，不进 CI）：`cd plugin && E2E_FRAMES=/tmp/frames.json node test/integration/real-model.mjs`，再用 `E2E_FRAMES=/tmp/frames.json ./gradlew :core:protocol:test` 让会话折叠逻辑回放真实帧。


```bash
cd app
./gradlew :core:protocol:test :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
# 对真实 dsh + 插件跑协议测试（需要 dsh、pnpm）：
cd ../plugin && node test/integration/kotlin-live.mjs
```

`assembleRelease` 开启 R8 minify + resource shrinking。未设置签名环境变量时使用 debug keystore；生产签名见仓库根 README「正式签名（CI）」——密钥来自 GitHub Secrets，切勿提交 keystore。

APK **不再**包含 `libpocket_iroh.so`；连接只走 host:port WebSocket。hello/pair 会交换 `appVersion` / `version` / `minimumAppVersion`，插件过旧时 App 显示主题化提示条。

## 使用

1. 电脑端：`dsh web` 装好插件后，设置 →「手机连接」打开配对（QR + `dshpocket://pair?h=host:port&c=`）。
2. 手机端：点击会话侧栏底部「设置」右侧的主机信息打开连接管理，再「扫码」或「输入地址」。电脑名称左侧的状态点实时显示连接状态：绿色在线、黄色连接中、灰色离线或未连接、红色认证失效；长名称省略时保留状态点。
3. 「附近设备」自动发现局域网 mDNS 主机；已配对设备显示地址、状态和 `Tailscale` / `LAN` 路由。旧 iroh 配置需重新配对。
4. token 用 Android Keystore 的 AES-GCM 密钥加密保存。

配对时名称输入框提示「默认远程主机 IP」；留空则使用远程主机地址作为名称，也可填写自定义名称。

设置 →「连接诊断」显示主机的完整诊断报告，不遮盖网络地址或截断实例 ID。点击「复制诊断报告」复制全文，也可长按报告文字选择并复制局部内容。

## 功能对齐

见 [docs/feature-parity.md](../docs/feature-parity.md)。界面与操作以官方桌面端为准，不因 Host 暴露 API 就新增产品功能：插件支持分组管理、安装检查/取消/卸载及配置；自动化任务支持搜索、规则编辑、投递记录和删除，新建跳转会话。默认模型配置和内置插件目录使用原生页面读取 Host API，不依赖整套 Host 网页加载。第三方 React 界面可通过插件页的独立「插件自定义界面」入口打开，依赖桌面本地 API 的功能仍有限制。主机 PTY 终端、浏览器、会话数据诊断、模型设置、轨迹、指令、导出、工作区文件、后台任务、通用设置和 `parentSessionId` 子会话均已有原生入口。

输入栏的权限切换按钮仅显示当前模式图标，保留无障碍标签，把宽度留给完整模型名称。权限选项来自当前 Host 的动态目录；Host 启用自动审查插件后才显示「自动审查」，启用时必须确认风险，且不能保存为新会话默认权限。

运行中连续发送默认使用「排队发送」，发送方式仍与桌面共享 `ui-conversation.busyEnter`；显式选择「插话发送」才引导当前轮次。排队消息使用紧贴输入框上沿的桌面同款紧凑条：单条直接预览，多条默认折叠为数量标题，可展开；仅未确认时显示「发送中」。已确认消息提供编辑、删除、插话操作，含附件或非文本内容不可文本编辑，插话仅在当前轮次运行时可用。操作结果以 Host 收件箱更新为准，正式消费后才进入聊天正文。回显通过 `requestId` 关联，重复文本不会相互吞并；发送失败清除对应回显，重连按 Host 收件箱恢复。

新会话首条消息点击后立即本地回显，并显示「发送中」。创建、配置与订阅期间保留消息，不切换为空白或整区加载；欢迎页与聊天页共用输入栏，保留键盘焦点和继续输入的草稿。首条确认前禁止重复提交，确认后恢复正常排队／插话。真实会话与快照沿用同一 `requestId` 去重；新会话发送不等待无关的权限回读和反馈查询。创建、配置或发送失败保留原文及错误，可「重新编辑」；离开会话后过期回执不能重新打开它或继续发送。

模型选择使用输入栏上方的紧凑两级浮层：先选择「模型」或「推理等级」，再进入分组列表；「+」和 `/model` 直接进入模型列表。模型入口和列表不重复显示 logo，列表只保留名称与选中标记；模型超过四个时显示可清空的模糊搜索。推理等级沿用 Host 名称及默认值，切换模型不继承旧模型的等级。成功后关闭，失败保留原选择；桌面端切换也会通过会话投影同步到手机。
模型与推理等级子菜单不显示额外的返回箭头或标题行，与桌面端一致；系统返回键或 Escape 返回上一级，点击浮层外部关闭菜单。

设置 →「模型」恢复原生提供商列表和单卡编辑，保留官方默认配置：API 密钥、地址、协议、模型目录、提供商添加与删除。列表末尾使用虚线「添加模型提供商」入口，支持目录提供商与自定义 API；模型选项按行展开。保存使用配置版本检查并回读确认，失败保留草稿；密钥不回显，删除先移除并确认配置，再清理此页面管理的密钥。

模型页暂不显示 Qoder 等插件自定义卡片，也没有「插件自定义界面 · 与桌面共用」中转入口，不进入 WebView。默认配置直接使用 `models.providers/providerGet/settingsMutate/discover` 与写入型凭据接口，不依赖 `ui.open`。

插件列表与详情保留独立的「打开插件自定义界面」，仅用于主动访问其他插件 Web 页面，不作为模型或内置插件的默认配置路径。其 WebView 使用 `MATCH_PARENT` 布局参数，避免 Chromium 的 `vh`/`dvh` 算成零；LAN/Tailscale 下的设置读取使用桥接提供的受信任 Host 管理声明。该可选入口需要相应桥接版本，安装 APK 本身不会重载桌面桥接。

自定义界面通过当前已认证连接领取 60 秒单次票据，由原生 HTTP 兑换 15 分钟 HttpOnly 会话；手机长期凭据和 Host 启动令牌不会交给 WebView。退出、主机断连或撤销配对会关闭对应网页会话；过期后使用「重新加载」。页面导航、请求及 WebSocket 限制在当前 Host，禁止文件/content 访问、证书绕过、设备权限、下载、文件选择及外部窗口。不兼容 Electron/桌面原生 API 的插件不会因此获得这些能力。该容器与普通浏览器使用不同入口和权限策略，但 Android WebView cookie 存储仍是应用级共享；服务端仅选择唯一有效且匹配当前 authority 的会话，防止其他路径的同名 cookie 干扰。

插件入口沿用桌面端的信息架构：侧栏「插件」直接显示「内置插件配置」「实验性插件」「已安装插件」，「更多」进入实验性插件列表，详情返回原列表；「设置 → 内置插件」单独显示原生只读目录，包括按 Agent 预设选择的会话插件、全局插件、搜索和状态详情。目录独立读取 `plugins.inventory`，不依赖包管理或 WebView，也不把预设声明转成全局开关。自动加载与手动刷新由同一加载流程管理，绑定当前连接与主机；无关能力变化不重启请求，刷新期间保留已加载目录，过期响应不能覆盖新连接结果。断线、缺少目录能力和读取失败均明确显示，不留下只有介绍的空页面。安装、启停、卸载及配置保留官方 Host 契约。

输入栏下方默认显示生成速度、缓存命中率和上下文占用；数据来自真实 Host 投影，缺失时不伪造数值。「性能与用量 → 详细」可查看全会话耗时、Token 用量等明细。目录失效通知和统计的实时更新需要桌面端加载新版桥接，安装 APK 本身不会重载电脑上的插件。

右侧栏使用全高侧面板：手机铺满宽度，横屏/宽屏靠右显示，最大宽度 480dp。「开始」页沿用官方罗盘和入口卡片；文件、文档预览、终端、浏览器、会话数据诊断共用返回/收起导航。入口不要求先手动选择会话，依赖 Host 会话的工具按当前工作区准备空白会话，不发送消息。浏览器使用手机 WebView，沿用桌面单行工具栏和文案，不添加额外说明；支持前进、后退、刷新、系统浏览器打开与手动恢复。诊断支持原始记录、对话分组、类型筛选、历史分页和 JSON 详情。后台任务位于对话/轨迹标签旁，任务清单位于输入栏上方。返回或收起终端面板只取消订阅，不结束主机 Shell；菜单中的「退出」才结束当前终端。

会话数据诊断沿用电脑端的单行展示形式下拉、十字选取图标、计数和跟踪操作；表格保留序号、类型、T/S、UTC 时间及数据列，窄屏横向滚动，对话分组不显示时间列。类型列的漏斗打开候选筛选浮层，确认后才应用；详情使用可拖动分隔线和 Object/Array 展开树，不添加电脑端没有的复制、JSON 切换或说明文字。选取图标进入实际聊天选取，返回键取消；点击消息后返回对应诊断记录，不触发消息按钮或发送。分组数据来自 Android 实际投影，不伪造桌面 JavaScript 对象。

终端使用 DSH 轻量工具栏：无逐键卡片边框，两行常驻，仅显示英文或按键符号 `Esc`、`Tab`、`↑`、`↓`、`Ctrl+C`、`Ctrl+D`、复制／粘贴，软键盘开关使用键盘图标。`Tab` 向远端 Shell 发送制表控制键，由 Shell 完成命令或路径补全。没有左右方向按钮，也没有额外快捷键菜单。Mac 仍用 `Ctrl+C` 中断、`Ctrl+D` 发送 EOF，本地复制／粘贴使用 `Cmd+C`／`Cmd+V`；Windows 使用 `Ctrl+V` 粘贴，有选区时 `Ctrl+C` 只复制。键盘弹出时工具条仍在顶部，按键不抢输入焦点。点击普通 Shell 的当前光标行会发送水平箭头定位，点击历史行不会发送上下键；支持鼠标协议的程序接收点击（SGR 支持完整坐标，legacy 限制在 ASCII 可传输坐标内），不发送应用拖动事件。长按直接选中触点词或字符，拖动扩选，期间冻结网格并屏蔽输入；复制保持软换行、硬换行及宽字符语义。多行粘贴仍需确认，断线禁用发送但保留输出供复制。

右上角 `⋯` 展示终端会话列表、当前项、新建和「退出」；「新建终端」只在该菜单出现。列表使用紧凑标题、短 ID、单行目录和当前项勾选，避免同名 Shell 无法区分。手机按连接配置和所属会话保存已知终端及最后成功附加的身份，重开面板／App 可重新发现 Host 保留的 Shell；列表失败不会删除记录，已不存在的指定终端不会偷偷替换成新 Shell。「退出」菜单项及确认弹窗中的「退出」「取消」按钮均使用 DSH 中性前景色，不使用红色或蓝色强调；操作仍需确认且只结束目标终端。保存的是终端身份，不是进程快照：Host 重启或官方闲置回收后无法恢复已消失的进程（默认无窗口保留且持续闲置约两小时会回收）。快捷键根据桥接 `terminal.list/create` 返回的远端 `platform` 自动匹配，不提供手动系统选择；旧桥接未返回系统信息时使用通用 Ctrl 标记，更新并重载电脑端桥接后即可自动识别。

后台任务入口按当前会话的真实任务列表显示：空列表隐藏；有运行中或正在停止的任务时显示进行中数量，否则显示保留任务总数。页面在前台且 Host 在线时每 3 秒刷新，切换会话、主机或断线会清空旧状态；查询失败显示「任务状态不可用」，不把失败当作零任务或继续展示旧的运行数量。

工作区按 Host 的真实实体管理，支持注册、重命名、移除、组内新会话、目录树、搜索摘要和会话排序；同名目录不会合并。「添加工作区」使用桌面的应用内目录选择器样式：面包屑、可编辑路径、双栏目录、隐藏文件开关、新建文件夹与取消／打开。窄屏横向滑动双栏，底部操作分两行；路径输入可前缀筛选并跟随目录层级，未提交草稿不会误打开旧目录。创建失败保留名称，成功后选中新目录；路径与名称保留合法首尾空格。桥接组合使用官方 `browse` 后端及客户端，电脑也使用应用内选择器，不再弹 macOS 系统窗口；连接其他仅有 `native` 的 Host 时保留完整路径输入。手机保持抽屉，宽屏在至少保留 480dp 主内容的条件下使用可折叠双栏。

目录选择器的「新建文件夹」「取消」采用官方中性描边按钮：36dp 高、12dp 圆角、14sp 字体和细边框，不使用 Material 默认强调色。新建窗口为 380dp 上限、28dp 圆角的嵌套弹窗，父级目录与选中状态保留；子级取消只丢弃名称草稿，不创建目录、不打开工作区，父级取消才退出目录选择器。浅色与深色均沿用桌面层级色。

审批和提问会接管输入区域，提交失败保留内容；多题分别保存答案并支持返回修改。目标栏通过官方 goal 投影及版本检查执行编辑、暂停、恢复、清除；后台任务可查看实时输出，终止需单独确认。`/` 命令与 `@` 引用从当前 Host 获取，不把固定菜单当作完整目录。

通用设置沿用桌面的紧凑分隔行及原文提示。权限、工作步骤展示、工作步骤收起时机、代码工作视图、繁忙发送行为和性能与用量的标题、说明及选项与桌面一致；不显示「移动端专属」分组、配置同步机制或「仅作用于本设备」等额外说明。字号为数值胶囊、内嵌上下箭头、外置 `px` 和同行「更多字体设置」图标；手机扩大透明点击区域，不依赖 hover。展开顺序为正文字体、代码字体、代码字号、终端字体、终端字号，每次重开页面默认折叠。字体列表用逗号分隔，失焦或 Enter／完成提交，留空恢复默认；字体在当前设备解析，不下载或使用电脑端字体。「工作步骤收起时机」只在本次应用实例保持；代码自动换行功能保留。Host 的 Session Log 上传开关保留版本检查和回读确认，错误时才显示恢复操作。预设名称、说明、默认值及只读 YAML 仍来自 Host。

手机是当前 Host 的控制端：语言、外观、字体与字号、工作步骤展示、性能与用量、繁忙发送行为、代码工作视图、默认权限和日志上传均读写桌面同一配置。手机保存携带 Host revision，成功后回读；桌面更改通过 `settings.changed` 更新手机已打开页面。离线、只读、版本冲突或配置覆盖不会伪装成保存成功，也不会把旧手机本地值上传覆盖桌面。切换主机清空旧镜像与未完成结果；只有连接、换行等设备专属项及客户端临时收起时机留在本机。
通用设置默认自动同步，不显示常驻同步说明或手动同步按钮；发生错误时才显示「重试」，读取或保存期间禁止重复操作。重试只重新读取配置，不重放失败的写入。

布局固定自动适配，不再提供「自动／手机／桌面」选择或持久化布局模式。宽度达到 760dp 时使用双栏侧栏，为会话保留至少 480dp；窄屏使用抽屉。旧布局选择不再参与渲染，侧栏自身的展开／收起交互保留。

Agent 预设页与桌面按「内置／自定义」分组展示卡片，手机单列、宽屏双列；卡片标记当前「新任务默认」，点击主体直接保存并回读确认，不再使用单选列表和额外保存按钮。已发布的内置模式提供完整中英文「模式说明／如何使用」双页帮助，查看帮助不改变默认项；「查看配置」先读取成功再打开只读 YAML 窗口，失败留在列表显示错误。自定义组的虚线创建入口进入创造模式新会话草稿，不自动发送消息或修改默认值。关闭代码工作视图时沿用桌面规则隐藏内置 PTC／极简卡片，用户自定义名称和说明保持原样。

预设页订阅 Host 配置变更：桌面修改默认预设后，已打开的手机页面会自动回读并更新「新任务默认」，后续保存使用最新 revision。保存期间收到的通知等待本次写入与回读结束后再刷新，不清除冲突或配置覆盖错误，也不关闭已打开的模式帮助。

新会话的模式入口只在预设目录可用时显示，使用实际默认项的名称，显式选择后保留用户选择；未加载或未提供模式时不显示虚构的默认模式名称。已开始会话仅显示该会话记录的预设，缺少预设记录时隐藏入口，不借用新任务默认值。内置名称与自定义发布名称遵循桌面同一规则。

聊天过程按桌面的正文与输入边界分组，完成轮次控制与过程组分开；标准模式默认收起过程组，详细模式运行时平铺。底部运行提示在思考、工具执行期间均保留“深度求索中”，使用 Host 轮次起点计时，配合官方鲸鱼动画、蓝色主题和文字高光；缺少起点不编造秒数。中途打开会话不会从手机连接时间重新计时。

文件页使用官方类型图标。预览支持可缩放原图、按需渲染的完整 PDF、Markdown、CSV/TSV 和禁止脚本／外网／本地资源访问的静态 HTML；Office 二进制文件不伪装为文本。PDF 原生渲染回归在 `PdfPreviewInstrumentedTest` 中，需要 Android 设备运行，Robolectric 截图不替代 PDFium 验证。

插件和自动化列表接收 Host 变更通知，同时保留手动刷新。自动化编辑支持常用 Cron 构建及高级原文，未修改的时间精度和时区别名保持不变；投递回执仍不代表模型执行完成。新增能力需要重载桌面桥接，仅安装 APK 不会替换运行中的 Host。
