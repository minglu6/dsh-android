# Android App

Gradle 工程根目录就是 `app/`。

| 模块 | 内容 |
|---|---|
| `core/protocol` | 纯 Kotlin/JVM：`PocketClient`（WebSocket）、`Transport`（Tailscale / LAN 路由标签）、`TranscriptReducer`、模型等数据结构 |
| `app` | Compose 界面、连接管理、前台服务（审批通知）、Keystore 加密 token |

界面和操作以官方 dsh 桌面/Web 为基准，配色和圆角沿用其主题；[docs/mockups](../docs/mockups/) 仅作早期设计参考，当前实现见 [功能对齐说明](../docs/desktop-parity.md)。

## 构建

真实模型端到端（仅本地，需要 `DEEPSEEK_API_KEY`，不进 CI）：`cd plugin && E2E_FRAMES=/tmp/frames.json node test/integration/real-model.mjs`，再用 `E2E_FRAMES=/tmp/frames.json ./gradlew :core:protocol:test` 让会话折叠逻辑回放真实帧。


```bash
cd app
./gradlew :core:protocol:test :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
# 对真实 dsh + 插件跑协议测试（需要 dsh、pnpm）：
cd ../plugin && node test/integration/kotlin-live.mjs
```

`assembleRelease` 开启 R8 minify + resource shrinking。未设置签名环境变量时使用 debug keystore；生产签名见仓库根 README「正式签名（CI）」——密钥来自 GitHub Secrets，切勿提交 keystore。

APK **不再**包含 `libpocket_iroh.so`；连接只走 host:port WebSocket。hello/pair 会交换 `appVersion` / `version` / `minimumAppVersion`，插件过旧时 App 显示主题化提示条。

## 使用

1. 电脑端：`dsh web` 装好插件后，设置 →「手机连接」打开配对（QR + `dshpocket://pair?h=host:port&c=`）。
2. 手机端：点击会话侧栏底部「设置」右侧的主机信息打开连接管理，再「扫码」或「输入地址」。电脑名称左侧的状态点实时显示连接状态：绿色在线、黄色连接中、灰色离线或未连接、红色认证失效；长名称省略时保留状态点。
3. 「附近设备」自动发现局域网 mDNS 主机；已配对设备显示地址、状态和 `Tailscale` / `LAN` 路由。旧 iroh 配置需重新配对。
4. token 用 Android Keystore 的 AES-GCM 密钥加密保存。

设置 →「连接诊断」显示主机的完整诊断报告，不遮盖网络地址或截断实例 ID。点击「复制诊断报告」复制全文，也可长按报告文字选择并复制局部内容。

## 功能对齐

见 [docs/feature-parity.md](../docs/feature-parity.md)。界面与操作以官方桌面端为准，不因 Host 暴露 API 就新增产品功能：插件支持分组管理、安装检查/取消/卸载及配置；自动化任务支持搜索、规则编辑、投递记录和删除，新建跳转会话。仅隐藏真正依赖桌面本地 UI 的功能（本机编辑器/目录选择器）；第三方插件自定义 React 界面仍需 Web，公开的 Host 配置可在手机编辑。主机 PTY 终端、浏览器、会话数据诊断、模型设置、轨迹、指令、导出、工作区文件、后台任务、通用设置和 `parentSessionId` 子会话均已有原生入口。

输入栏的权限切换按钮仅显示当前模式图标，保留无障碍标签，把宽度留给完整模型名称。权限选项来自当前 Host 的动态目录；Host 启用自动审查插件后才显示「自动审查」，启用时必须确认风险，且不能保存为新会话默认权限。

模型选择使用输入栏上方的紧凑两级浮层：先选择「模型」或「推理等级」，再进入分组列表；「+」和 `/model` 直接进入模型列表。模型入口和列表不重复显示 logo，列表只保留名称与选中标记；模型超过四个时显示可清空的模糊搜索。推理等级沿用 Host 名称及默认值，切换模型不继承旧模型的等级。成功后关闭，失败保留原选择；桌面端切换也会通过会话投影同步到手机。
模型与推理等级子菜单不显示额外的返回箭头或标题行，与桌面端一致；系统返回键或 Escape 返回上一级，点击浮层外部关闭菜单。

设置中的模型页采用桌面的提供商列表与单卡展开：API 密钥为主字段，地址、协议及模型选项放在「自定义设置」折叠区；模型使用原生字段编辑，不要求输入 JSON。添加提供商分为「第三方模型提供商」与「自定义模型 API」，发现的模型先选择再加入。API Key 仅在提供商内配置，没有独立凭证管理页，不读取已存密钥。保存使用配置版本检查，冲突或密钥写入失败保留草稿；桌面外部修改在重开卡片时回读。

输入栏下方默认显示生成速度、缓存命中率和上下文占用；数据来自真实 Host 投影，缺失时不伪造数值。「性能与用量 → 详细」可查看全会话耗时、Token 用量等明细。目录失效通知和统计的实时更新需要桌面端加载新版桥接，安装 APK 本身不会重载电脑上的插件。

右侧栏使用全高侧面板：手机铺满宽度，横屏/宽屏靠右显示，最大宽度 480dp。「开始」页沿用官方罗盘和入口卡片；文件、文档预览、终端、浏览器、会话数据诊断共用返回/收起导航。入口不要求先手动选择会话，依赖 Host 会话的工具按当前工作区准备空白会话，不发送消息。浏览器使用手机 WebView，沿用桌面单行工具栏和文案，不添加额外说明；支持前进、后退、刷新、系统浏览器打开与手动恢复。诊断支持原始记录、对话分组、类型筛选、历史分页和 JSON 详情。后台任务位于对话/轨迹标签旁，任务清单位于输入栏上方。退出终端只取消订阅，不结束主机 Shell。

后台任务入口按当前会话的真实任务列表显示：空列表隐藏；有运行中或正在停止的任务时显示进行中数量，否则显示保留任务总数。页面在前台且 Host 在线时每 3 秒刷新，切换会话、主机或断线会清空旧状态；查询失败显示「任务状态不可用」，不把失败当作零任务或继续展示旧的运行数量。

工作区按 Host 的真实实体管理，支持注册、重命名、移除、组内新会话、目录树、搜索摘要和会话排序；同名目录不会合并。Host 提供 `browse` 目录能力时可以逐级选择目录；macOS `native` 目录选择器不支持远程枚举时，只显示完整路径输入，不在电脑上弹出系统窗口。手机保持抽屉，宽屏在至少保留 480dp 主内容的条件下使用可折叠双栏。

审批和提问会接管输入区域，提交失败保留内容；多题分别保存答案并支持返回修改。目标栏通过官方 goal 投影及版本检查执行编辑、暂停、恢复、清除；后台任务可查看实时输出，终止需单独确认。`/` 命令与 `@` 引用从当前 Host 获取，不把固定菜单当作完整目录。

外观使用官方浅色／深色／跟随系统图卡，偏好修改立即重绘；会话、代码和终端字号独立设置。预设页面显示 Host 名称、说明、默认值和只读 YAML，默认值写入使用版本检查。

文件页使用官方类型图标。预览支持可缩放原图、按需渲染的完整 PDF、Markdown、CSV/TSV 和禁止脚本／外网／本地资源访问的静态 HTML；Office 二进制文件不伪装为文本。PDF 原生渲染回归在 `PdfPreviewInstrumentedTest` 中，需要 Android 设备运行，Robolectric 截图不替代 PDFium 验证。

插件和自动化列表接收 Host 变更通知，同时保留手动刷新。自动化编辑支持常用 Cron 构建及高级原文，未修改的时间精度和时区别名保持不变；投递回执仍不代表模型执行完成。新增能力需要重载桌面桥接，仅安装 APK 不会替换运行中的 Host。
